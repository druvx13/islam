# The Meaning of the Glorious Qur'an by Mohammed Marmaduke Pickthall

This is an independent website containing M.M. Pickthall's English rendering of the Qur'an.

## About This Translation

**Translator:** Mohammed Marmaduke Pickthall  
**Published:** 1938  
**Publisher:** Government Central Press, Hyderabad-Deccan

This translation is technically not in the public domain in the US, because it was published in India after 1922. However, Pickthall died in 1936, so it is now in the public domain in countries with the death+50 public domain rule (e.g. Australia, Pakistan, Canada), and it is also in the public domain in countries with the death+70 rule (e.g. UK and countries in the European Union), as of the end of 2006.
